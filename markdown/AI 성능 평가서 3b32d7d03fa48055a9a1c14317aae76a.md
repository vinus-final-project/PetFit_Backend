# AI 성능 평가서

# 문서 개요

본 문서는 Pet Fit 서비스에서 사용하는 **영상 기반 AI 분석 시스템**의 성능을 평가하기 위한 기준과 결과를 정의한다.

성능평가는 객체 탐지 모델, 환경 분석 모델뿐만 아니라 영상 처리부터 최종 결과 생성까지의 전체 AI 파이프라인을 대상으로 수행한다.

평가 대상은 성격에 따라 둘로 나뉜다.

| 구분 | 대상 | 평가 방식 |
| --- | --- | --- |
| 모델 성능 | 객체 탐지, 환경 분석 | 정확도·속도 측정 후 모델 선정 |
| 규칙 검증 | Score Generator, 탐지 신뢰 기준, 위험도 판정 | 명세 일치 여부와 결정성 확인 |

규칙 기반 구성 요소는 정답이 정의되어 있으므로 정확도가 아니라 **명세와의 일치 여부**를 검증한다.

---

# 평가 목적

- 영상 기반 AI 분석 성능 검증
- **학습 데이터셋 품질 검증** (탐지 대상 12종 중 8종이 커스텀 학습 대상)
- 객체 탐지 모델 비교 및 클래스별 성능 확인
- **탐지 신뢰 기준 검증** (오탐 제거율과 정탐 손실률의 균형)
- **Pet Fit Score 산출 검증** (계산식 일치, 결정성)
- 생성형 AI 분석 품질 비교 및 `OBSERVED` 정탐률 측정
- Apple Silicon 최적화 검증
- **미확정 임계값 보정** (점유율 구간, confidence, 프레임 추출 간격)
- 최종 AI 모델 선정

# 학습 데이터셋

## 커스텀 학습 필요성

탐지 대상 12종 중 **8종은 COCO 사전학습 클래스에 존재하지 않는다.**

사전학습 모델만으로는 핵심 위험 요소인 전선을 탐지할 수 없으므로 커스텀 학습이 필수이다.

## 위험도 판정 성능

`risk_level` 은 탐지 객체와 반려동물 그룹의 조합으로 판정한다. 판정 규칙은 AI 분석 정의서를 따른다.

| 평가 항목 | 설명 |
| --- | --- |
| 판정 일치율 | 규칙표와 실제 판정 결과의 일치 여부 |
| 그룹별 판정 검증 | 동일 객체가 그룹에 따라 다른 등급으로 판정되는지 확인 |
| **최소 위험도 적용** | 전선이 모든 그룹에서 `HIGH` 로 판정되는지 확인 |
| SAFE 제외 확인 | SAFE 객체가 마킹 대상에서 제외되는지 확인 |

### 최소 위험도 검증

중요도만 따르면 전선은 고양이에게 `MEDIUM`(노란색)이 된다. 하한이 적용되어 `HIGH`(빨간색)로 표시되는지 확인한다.

| 입력 | 기대 결과 |
| --- | --- |
| 전선 + 고양이 | HIGH (하한 적용) |
| 전선 + 소형견 | HIGH |
| 창문 + 소형견 | LOW (하한 없음) |

## Pet Fit Score 산출 성능

Score Generator는 규칙 기반이므로 정답이 정의되어 있다. 정확도가 아니라 **명세 일치 여부**를 검증한다.

| 평가 항목 | 검증 방법 | 기대 결과 |
| --- | --- | --- |
| 결정성 | 동일 입력을 반복 산출 | 항상 동일한 점수 |
| 점유율 상한 | 겹치는 Bounding Box가 있는 프레임 | 점유율이 1.0을 초과하지 않음 |
| 점유율 합집합 | 완전히 겹친 박스 2개 | 큰 박스 하나의 면적과 동일 |
| 점유율 정확도 | 겹치지 않는 박스 여러 개 | 개별 면적의 단순 합과 정확히 일치 |
| 점유율 경계값 | 박스 경계가 맞닿은 두 박스 | 중복 계산 없이 두 면적의 합 |
| 중앙값 짝수 처리 | 프레임 수가 짝수인 영상 | 가운데 두 값의 평균 |
| 임계값 경계 | 점유율이 0.40에 근접한 입력 | 4자리 정규화 후 비교, 판정이 뒤집히지 않음 |
| 대표 프레임 결정성 | 동점이 발생하는 입력 | 우선순위 규칙으로 항상 하나가 선정됨 |
| 결과 정렬 결정성 | 동일 입력 반복 요청 | 목록 순서가 항상 동일 |
| **공간별 항목 제외** | 동일 탐지 결과를 공간만 바꿔 산출 | 미적용 항목이 가중치 합에서 제외됨 |
| **전 항목 제외 처리** | 침실에서 생활환경 평가 | 산출 항목이 없으므로 100 |
| 계산식 일치 | AI 분석 정의서 계산 예시로 단위 테스트 | 소형견 예시 total = 56 |
| 점수 범위 | 임의 입력에 대한 산출 결과 검사 | 모든 점수가 0 이상 100 이하 |
| 비중 합계 | 평가 항목 비중 합산 | 0.40 + 0.25 + 0.20 + 0.15 = 1.00 |
| 산출 불가 처리 | 판정 객체가 없는 항목 포함 시 | 가중치 합에서 제외되는지 확인 |
| 전 항목 산출 불가 | 해당 평가 항목의 모든 항목이 산출 불가 | 해당 항목 100으로 처리 |
| 중요도 이중 반영 | 감점률에 risk_level 미사용 확인 | 그룹 차이가 가중치로만 반영 |
| 산출 시간 | 점수 계산 소요 시간 | 측정 후 기입 |

### 단위 테스트 기준값

동일한 탐지 결과(전선·창문·카펫·소파·급수기, 점유율 0.35)를 소형견 기준으로 공간만 바꿔 검증한다.

| 공간 | safety | activity | rest | environment | total |
| --- | --- | --- | --- | --- | --- |
| 거실 | 50 | 67 | 60 | 50 | **56** |
| 침실 | 50 | 67 | 60 | 100 | **64** |
| 베란다 | 33 | 100 | 100 | 100 | **73** |

침실은 급식·급수 환경이, 베란다는 탐지형 외 전 항목이 제외된다. 공간별 제외가 정상 동작하면 위 값이 재현된다.

| OBSERVED 오탐률 | 이미지에 없는 위험 요소를 생성한 비율 |
| OBSERVED 발견 가치 | 탐지 대상 밖의 위험 요소를 새로 찾아낸 건수 |

### OBSERVED 항목 평가

`OBSERVED` 는 근거가 이미지이므로 자동 검증이 불가능하다. 사람이 이미지와 대조하여 판정한다.

점수에 영향을 주지 않으므로 오탐이 발생해도 Pet Fit Score의 재현성은 유지된다. 다만 사용자에게 잘못된 경고를 표시하므로 오탐률을 관리한다.

| 판정 | 기준 |
| --- | --- |
| 정탐 | 이미지에서 해당 위험 요소가 확인된다 |
| 오탐 | 이미지에서 확인되지 않는다 |
| 과장 | 존재하지만 위험 수준을 과장했다 |
| 응답 시간 | 분석 결과 생성 시간 |
| 운영 비용 | API 또는 로컬 실행 비용 |

# 종합 의견

- 영상 기반 AI 파이프라인 전체의 성능을 종합적으로 평가한다.
- 객체 탐지 성능뿐만 아니라 객체 추적, 대표 프레임 생성, 위험 객체 마킹의 정확도를 함께 검증한다.
- 탐지 대상 12종 중 8종은 커스텀 학습이 필요하므로, 데이터셋 품질이 전체 성능을 좌우한다. 클래스별 탐지 성능을 개별 확인한다.
- 점수 산출에 기여하지 않는 클래스는 라벨링 비용만 발생시키므로 탐지 대상에서 제외한다.
- 특히 `cable` 은 핵심 위험 요소이면서 형태가 가늘고 배경과 유사하여 탐지 난이도가 높다. 별도 확인이 필요하다.
- Score Generator는 규칙 기반이므로 정확도가 아니라 명세 일치 여부와 결정성을 검증한다.
- Apple Silicon(MPS/MLX) 환경에서의 처리 효율을 고려하여 최종 모델을 선정한다.
- 성능평가 결과를 기반으로 객체 탐지 모델과 환경 분석 모델을 최종 확정하여 Pet Fit 서비스에 적용한다.
