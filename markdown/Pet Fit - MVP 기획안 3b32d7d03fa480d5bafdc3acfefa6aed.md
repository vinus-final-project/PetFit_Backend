# Pet Fit - MVP 기획안

## 프로젝트명

**Pet Fit**

---

# 프로젝트 소개

Pet Fit은 **영상 기반 AI 반려동물 생활환경 분석 서비스**이다.

사용자는 자신의 **반려동물 그룹**을 선택한 후 생활공간을 일정 시간 촬영하면 AI가 촬영된 영상을 분석하여 공간 내 객체를 탐지하고, 반려동물 그룹의 특성을 반영한 생활환경 분석을 수행한다.

AI는 영상에서 다양한 프레임을 추출하여 객체를 탐지하고, 객체 추적(Object Tracking)을 통해 중복 탐지를 제거한 후 위험 요소를 판단한다.

이후 **위험 요소마다 가장 잘 보이는 장면에 마킹한 이미지**를 개별 생성하고, Pet Fit Score 및 맞춤형 환경 개선 방안을 함께 제공한다.

점수는 **규칙 기반으로 산출**하고, 서술과 개선 추천은 **생성형 AI**가 담당한다. 역할을 나누어 점수의 재현성과 서술의 유연성을 함께 확보한다.

기존 AI 인테리어 서비스가 공간 디자인이나 가구 추천에 집중하는 것과 달리, Pet Fit은 **반려동물의 안전성과 생활 편의성을 고려한 생활환경 분석**을 목표로 한다.

# 개발 배경

반려동물 양육 가구가 증가하면서 반려동물의 생활환경에 대한 관심도 지속적으로 높아지고 있다.

하지만 보호자가 현재 생활공간이 반려동물에게 적합한 환경인지 객관적으로 판단하기는 쉽지 않다.

기존 AI 서비스는 대부분 인테리어 디자인이나 가구 추천에 초점을 맞추고 있으며, 반려동물의 생활 특성을 반영한 환경 분석 서비스는 부족한 상황이다.

또한 단일 이미지를 기반으로 한 분석은 공간 전체를 파악하기 어렵다는 한계가 있다.

Pet Fit은 **영상 기반 분석**을 통해 다양한 시점에서 공간을 인식하고, AI 객체 탐지와 생성형 AI를 활용하여 보다 신뢰성 있는 생활환경 분석 서비스를 제공하는 것을 목표로 한다.

## 실시간 촬영 가이드

영상 촬영 중 AI가 올바른 촬영을 위한 가이드를 제공한다.

예시

- 방 전체가 화면에 보이도록 촬영해주세요.
- 카메라를 조금 뒤로 이동해주세요.
- 조명이 부족합니다.
- 바닥이 화면에 포함되도록 촬영해주세요.
- 공간을 천천히 촬영해주세요.

---

## 영상 촬영

사용자는 생활공간을 촬영한다.

| 항목 | 값 |
| --- | --- |
| 권장 길이 | 5 ~ 10초 |
| 허용 길이 | 3 ~ 30초 |
| 형식 | MP4 (H.264) |
| 최대 크기 | 100MB |

촬영 가이드는 권장 길이를 안내하며, 허용 범위를 벗어난 영상은 업로드 시 거부된다.

촬영 완료 후 영상을 AI 서버로 전달한다.

---

## 프레임 추출

AI는 촬영된 영상에서 프레임을 균등 간격으로 추출한다.

기준은 초당 3프레임이며, 결과가 15~30장 범위를 벗어나면 간격을 조정하여 장수를 맞춘다.

| 영상 길이 | 추출 프레임 |
| --- | --- |
| 3초 | 15장 |
| 5 ~ 10초 | 15 ~ 30장 |
| 30초 | 30장 |

## 객체 추적(Object Tracking)

영상에서 동일한 객체를 추적하여 중복 탐지를 제거하고 객체 정보를 통합한다.

---

## 위험 객체 마킹

위험 요소로 판단된 객체마다 **개별 마킹 이미지를 생성한다.**

각 이미지는 해당 객체가 가장 잘 보이는 프레임에 그 객체의 Bounding Box 하나만 표시한다.

공간을 이동하며 촬영하므로 위험 요소가 서로 다른 장면에 나타난다. 한 장에 모두 담으면 다른 장면의 위험 요소를 표시할 수 없다.

예시

- 전선 → 빨간색 (3번 프레임)
- 계단 → 노란색 (25번 프레임)
- 창문 → 빨간색 (18번 프레임)

## 반려동물 그룹 맞춤 환경 분석

객체 탐지 결과를 기반으로 생활환경을 분석한다.

분석 항목은 9종이며, 반려동물 그룹마다 중요도가 다르다. 아래는 각 그룹에서 **매우 중요(●●)** 하게 다루는 항목이다.

### 소형견

- **전선 노출** ●●
- 미끄럼 위험 · 계단 위험 · 활동 공간 · 휴식 공간 · 급식·급수 환경

### 중·대형견

- **전선 노출 · 활동 공간 · 미끄럼 위험 · 계단 위험** ●●
- 휴식 공간 · 급식·급수 환경

### 고양이

- **창문 안전 · 수직 공간 · 숨을 공간** ●●
- 전선 노출 · 활동 공간 · 휴식 공간 · 급식·급수 환경

> ※ 전체 분석 항목과 그룹별 중요도는 AI 분석 정의서를 따른다.
> 
> ※ `숨을 공간` 은 판정할 탐지 객체가 정의되지 않아 MVP에서는 점수에 반영하지 않는다.

## Pet Fit Score

**규칙 기반으로 산출한다.** 생성형 AI는 점수를 만들지 않는다.

탐지된 객체와 반려동물 그룹별 중요도를 가중치로 적용하여 계산한다.

| 평가 항목 | 비중 |
| --- | --- |
| 안전성 | 40% |
| 활동성 | 25% |
| 휴식환경 | 20% |
| 생활환경 | 15% |

### 규칙 기반으로 산출하는 이유

| 항목 | 내용 |
| --- | --- |
| 재현성 | 같은 공간을 다시 촬영해도 같은 점수가 나온다 |
| 설명 가능성 | 어느 항목에서 몇 점이 깎였는지 추적할 수 있다 |
| 검증 가능성 | 단위 테스트로 계산을 확인할 수 있다 |

생성형 AI가 점수를 만들면 동일한 환경에도 점수가 달라져 보호자가 결과를 신뢰하기 어렵다.

산출된 점수는 생성형 AI에 입력으로 전달하여, 점수와 서술이 어긋나지 않도록 한다.

# 서비스 흐름

사용자 관점의 흐름이다.

```
앱 실행
        │
        ▼
반려동물 그룹 선택
        │
        ▼
공간 종류 선택
        │
        ▼
실시간 촬영 가이드
        │
        ▼
영상 촬영
        │
        ▼
분석 요청
        │
        ▼
분석 진행 상태 확인
        │
        ▼
[ AI 분석 파이프라인 ]
        │
        ├── 실패 ──▶ 분석 실패 안내
        │              ├── 재시도 (최대 3회)
        │              └── 재촬영
        ▼
결과 화면
        │
        ▼
분석 결과 저장
```

> ※ AI 분석 파이프라인의 상세 단계는 **AI 설계서**를 따른다.
