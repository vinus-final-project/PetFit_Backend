# 기능 명세서

# 문서 개요

본 문서는 Pet Fit 서비스의 기능을 정의한다.

영상 기반 AI 분석 서비스를 기준으로 각 기능의 입력값, 출력값, 예외 처리 및 우선순위를 정의한다.

---

| 기능 ID | 기능명 | 기능 설명 | 입력값 | 출력값 | 예외 처리 | 우선순위 |
| --- | --- | --- | --- | --- | --- | --- |
| FN-001 | 반려동물 그룹 선택 | 분석 대상 반려동물 그룹을 선택한다. | animalGroup | 선택된 그룹 | 그룹 미선택 | 필수 |
| FN-026 | 공간 종류 선택 | 촬영할 공간 종류를 선택한다. | spaceType | 선택된 공간 | 공간 미선택 | 필수 |
| FN-002 | 카메라 실행 | 카메라를 실행한다. | 없음 | 카메라 화면 | 권한 거부 | 필수 |
| FN-003 | 실시간 촬영 가이드 | 올바른 촬영을 위한 가이드를 제공한다. 온디바이스에서 처리하며 서버 통신은 발생하지 않는다. | 카메라 영상 | 가이드 메시지 | 없음 | 필수 |
| FN-004 | 영상 촬영 | 생활공간을 영상으로 촬영한다. | 촬영 시작 | 영상 파일 | 촬영 실패 | 필수 |
| FN-020 | 재촬영 | 촬영한 영상을 폐기하고 다시 촬영한다. | 재촬영 요청 | 초기화된 촬영 화면 | 없음 | 필수 |
| FN-005 | AI 분석 요청 | 촬영된 영상을 AI 서버로 전송한다. 서버는 즉시 분석 ID를 반환한다. | 영상, animalGroup | 분석 ID, 상태 | 네트워크 오류 | 필수 |
| FN-018 | 분석 진행 상태 조회 | 분석 진행 상태와 단계를 주기적으로 조회한다. | 분석 ID | 상태, 단계, 진행률 | 조회 실패, 시간 초과 | 필수 |
| FN-027 | 분석 실패 안내 | 실패 화면을 구성하고 실패 단계에 맞는 행동을 안내한다. | 상태, 실패 단계, 재시도 가능 여부 | 실패 화면 | 표시 실패 | 필수 |
| FN-021 | 분석 재시도 | 실패한 분석을 기존 영상으로 다시 수행한다. | 분석 ID | 재시도 접수 | 재시도 불가, 횟수 초과 | 필수 |
| FN-006 | 프레임 추출 | 영상에서 균등 간격으로 15~30장을 추출한다. | 영상 | 프레임 목록 | 추출 실패 | 필수 |
| FN-007 | 객체 탐지 | 프레임에서 객체를 탐지한다. | 프레임 | 프레임별 탐지 결과 | 탐지 실패 | 필수 |
| FN-022 | 활동 공간 점유율 산출 | 프레임별 점유율을 산출하고 중앙값을 결정한다. | 프레임별 탐지 결과 | 점유율 | 산출 실패 | 필수 |
| FN-008 | 객체 추적 | 동일 객체를 추적하여 중복을 제거한다. | 프레임별 탐지 결과 | 통합 객체 목록 | 추적 실패 | 필수 |
| FN-023 | 탐지 신뢰 기준 적용 | 신뢰도와 탐지 프레임 수로 오탐을 제거한다. | 통합 객체 목록 | 채택된 객체 목록 | 판정 실패 | 필수 |
| FN-024 | 객체명 변환 | 클래스 코드를 한글 객체명으로 변환한다. | 채택된 객체 목록 | 한글명 부여 객체 목록 | 매핑 누락 | 필수 |
| FN-025 | 위험도 판정 | 객체와 반려동물 그룹으로 위험 수준을 판정한다. | 객체 목록, animalGroup | risk_level 부여 객체 목록 | 판정 실패 | 필수 |
| FN-009 | 대표 프레임 생성 | 썸네일용 분석 대표 프레임과 위험 객체별 대표 프레임을 선정한다. | 프레임 목록, 객체 정보 | 분석 대표 프레임, 객체별 대표 프레임 | 생성 실패 | 필수 |
| FN-010 | 위험 객체 마킹 | 위험 객체마다 해당 객체의 대표 프레임에 Bounding Box를 표시한 이미지를 생성한다. | 객체별 대표 프레임, 객체 정보 | 객체별 마킹 이미지 | 마킹 실패 | 필수 |
| FN-012 | Pet Fit Score 생성 | 탐지 객체와 점유율을 기준으로 규칙 기반 점수를 산출한다. | 객체 목록, 점유율, animalGroup | Pet Fit Score | 점수 생성 실패 | 필수 |
| FN-011 | 반려동물 그룹 맞춤 환경 분석 | 객체 정보·점수·원본 프레임 이미지를 기반으로 환경을 분석한다. | 객체 목록, animalGroup, Pet Fit Score, 원본 프레임 이미지 | 환경 분석 결과, 위험 요소 | 분석 실패 | 필수 |
| FN-013 | 환경 개선 추천 | 맞춤형 개선 방안을 생성한다. | FN-011과 동일 | 추천 목록 | 추천 생성 실패 | 필수 |
| FN-014 | 분석 결과 제공 | 결과 화면을 구성한다. | 점수, 마킹 이미지, 위험 요소, 분석 서술, 추천 | 결과 화면 | 표시 실패 | 필수 |
| FN-015 | 분석 결과 저장 | 분석 결과를 저장한다. | 분석 결과 | 저장 완료 | 저장 실패 | 필수 |
| FN-016 | 분석 이력 조회 | 자신의 기기에서 요청한 분석 이력을 페이지 단위로 조회한다. | 조회 요청, 기기 식별자, 페이지 정보 | 분석 이력, 페이지 정보 | 조회 실패 | 필수 |
| FN-017 | 분석 결과 삭제 | 저장된 결과와 관련 파일을 삭제한다. 진행 중인 분석은 삭제할 수 없다. | 삭제 요청, 기기 식별자 | 삭제 완료 | 삭제 실패, 권한 없음, 진행 중 | 선택 |
| FN-019 | 기기 식별자 생성 | 앱 최초 실행 시 UUID를 생성하여 로컬에 저장한다. | 없음 | 기기 식별자 | 저장 실패 | 필수 |

> ※ `FN-011` 과 `FN-013` 은 LLM/VLM **1회 호출로 함께 생성**된다. 기능은 구분하되 구현은 단일 호출이다.
> 
> ※ `FN-012` 는 `FN-011` 보다 먼저 실행된다. 산출된 점수를 LLM 입력으로 전달한다.
> 
> ※ AI 분석 단계의 실행 순서와 구성 요소는 AI 설계서를 따른다.

# 기능 흐름

```
기기 식별자 생성 (최초 1회)
        │
        ▼
반려동물 그룹 선택
        │
        ▼
공간 종류 선택
        │
        ▼
카메라 실행
        │
        ▼
실시간 촬영 가이드
        │
        ▼
영상 촬영 ◀──────────── 재촬영
        │
        ▼
AI 분석 요청
        │
        ▼
분석 ID 수신 (즉시 응답)
        │
        ▼
분석 진행 상태 조회 ◀───┐
        │              │
        │  진행 중이면 ─┘
        │
        ├── 실패 ──▶ 분석 실패 안내
        │              ├── 재시도 ──┘ (최대 3회)
        │              └── 재촬영 ──▶ 영상 촬영
        ▼
[ FN-006 ~ FN-013 AI 분석 ]
  프레임 추출 · 객체 탐지 · 객체 추적
  대표 프레임 생성 · 위험 객체 마킹
  Pet Fit Score 생성 · 환경 분석 · 개선 추천
        │
        ▼
분석 결과 제공
        │
        ▼
분석 결과 저장
        │
        ▼
분석 이력 조회
```

# 기능별 상세 설명

| 기능 | 설명 |
| --- | --- |
| 반려동물 그룹 선택 | 사용자가 분석 기준이 될 반려동물 그룹을 선택한다. |
| 공간 종류 선택 | 촬영할 공간을 선택한다. 공간에 따라 평가하는 분석 항목이 달라진다. |
| 카메라 실행 | 카메라를 실행하여 촬영 화면을 제공한다. |
| 실시간 촬영 가이드 | 공간 전체가 촬영될 수 있도록 가이드를 제공한다. 온디바이스 처리이므로 대응 API가 없다. |
| 영상 촬영 | 생활공간을 일정 시간 촬영한다. |
| 재촬영 | 촬영 결과가 만족스럽지 않거나 분석에 실패한 경우 다시 촬영한다. |
| AI 분석 요청 | 촬영이 완료된 영상을 AI 서버로 전송한다. 서버는 접수 후 즉시 분석 ID를 반환하고 백그라운드로 처리한다. |
| 분석 진행 상태 조회 | 분석 진행 상태·단계·진행률을 주기적으로 조회하여 분석 중 화면에 표시한다. |
| 분석 실패 안내 | 실패 화면을 표시한다. 실패 단계가 영상 품질 문제면 재촬영을, 서버 오류면 재시도를 주 행동으로 안내한다. |
| 분석 재시도 | 실패한 분석을 기존 영상으로 다시 수행한다. 영상 재전송 없이 최대 3회까지 시도한다. 재시도 가능 여부에 따라 버튼 노출을 제어한다. |
| 프레임 추출 | 영상 길이에 따라 간격을 조정하여 15~30장을 균등 추출한다. |
| 객체 탐지 | YOLO를 이용하여 프레임 단위로 객체를 탐지한다. |
| 활동 공간 점유율 산출 | 프레임별 Bounding Box 합집합 면적 비율의 중앙값을 구한다. 객체 추적 이전에 실행한다. |
| 객체 추적 | 동일 객체를 추적하여 중복 탐지를 제거하고 신뢰도·탐지 프레임 수를 산출한다. |
| 탐지 신뢰 기준 적용 | 신뢰도 0.40 미만이거나 탐지 프레임 2장 미만인 객체를 오탐으로 제거한다. |
| 객체명 변환 | YOLO 클래스 코드를 한글 객체명으로 변환한다. 매핑표에 없는 코드는 무시한다. |
| 위험도 판정 | 탐지 객체와 반려동물 그룹의 조합으로 위험 수준을 결정한다. 마킹 색상에만 사용한다. |
| 대표 프레임 생성 | 썸네일용 대표 프레임 1장과, 위험 객체마다 가장 잘 보이는 프레임을 선정한다. |
| 위험 객체 마킹 | 위험 객체 1개당 이미지 1장을 생성하고 색상과 Bounding Box로 표시한다. SAFE는 생성하지 않는다. |
| Pet Fit Score 생성 | 탐지 객체와 반려동물 그룹별 중요도를 기준으로 규칙 기반 점수를 산출한다. |
| 반려동물 그룹 맞춤 환경 분석 | 반려동물 그룹 기준으로 생활환경을 분석한다. 점수와 원본 프레임 이미지를 입력으로 사용한다. |
| 환경 개선 추천 | 위험 요소에 대한 개선 방안을 생성한다. 환경 분석과 함께 생성된다. |
| 분석 결과 제공 | 점수, 위험 요소별 마킹 이미지, 분석 서술, 개선 추천을 제공한다. |
| 분석 결과 저장 | 분석 결과를 저장한다. |
| 분석 이력 조회 | 자신의 기기에서 요청한 분석 이력만 페이지 단위로 조회한다. |
| 분석 결과 삭제 | 저장된 결과와 업로드 영상·생성 이미지를 함께 삭제한다. |
| 기기 식별자 생성 | 회원 기능이 없으므로 UUID로 분석 이력을 기기 단위로 분리한다. |
