## 영상 촬영

| 요구사항 ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-101 | 카메라 실행 | 카메라를 실행한다. | 필수 |
| FR-102 | 실시간 촬영 가이드 | 올바른 촬영을 위한 가이드를 제공한다. 온디바이스에서 처리한다. | 필수 |
| FR-103 | 영상 촬영 | 생활공간을 영상으로 촬영한다. | 필수 |
| FR-104 | 재촬영 | 촬영 영상을 폐기하고 다시 촬영한다. | 필수 |
| FR-105 | 영상 분석 요청 | 촬영 완료 후 영상을 AI 서버로 전송한다. 서버는 즉시 분석 ID를 반환한다. | 필수 |
| FR-106 | 분석 진행 상태 조회 | 분석 진행 상태·단계·진행률을 주기적으로 조회한다. | 필수 |
| FR-107 | 분석 시간 초과 처리 | 최대 대기 시간을 초과하면 분석 실패로 처리하고 재촬영을 안내한다. | 필수 |
| FR-108 | 분석 재시도 | 실패한 분석을 기존 영상으로 다시 수행한다. 최대 3회까지 시도할 수 있다. | 필수 |
| FR-109 | 분석 실패 안내 | 분석 실패 시 실패 화면을 표시하고 실패 단계에 맞는 다음 행동을 안내한다. | 필수 |
| FR-110 | 재시도 버튼 제어 | 재시도 가능 여부에 따라 재시도 버튼의 노출을 제어한다. | 필수 |

> ※ 실시간 촬영 가이드는 카메라 프리뷰를 클라이언트에서 판정하므로 대응 API가 없다. 영상을 서버로 전송하지 않는다.

### 실패 단계별 안내

실패 지점에 따라 권장하는 행동이 다르다. 서버가 반환한 `stage` 로 분기한다.

| 실패 단계 | 원인 추정 | 주 행동 | 보조 행동 |
| --- | --- | --- | --- |
| 프레임 추출 · 객체 탐지 | 영상 품질 문제 | **재촬영** | 재시도 |
| 대표 프레임 · 마킹 · 점수 산출 · 환경 분석 | 서버 일시 오류 | **재시도** | 재촬영 |

재시도 횟수를 모두 소진하면 재시도 버튼을 숨기고 재촬영만 안내한다.

# 비기능 요구사항

| 요구사항 ID | 항목 | 설명 |

| NFR-001 | 성능 | 영상 분석 후 목표 시간 내 결과를 제공해야 한다. |

| NFR-004 | 확장성 | 새로운 반려동물 그룹과 AI 모델을 쉽게 추가할 수 있어야 한다. |
| NFR-005 | 데이터 관리 | 분석 결과를 안전하게 저장하고 조회할 수 있어야 한다. |

# 사용자 흐름

```
앱 실행
    │
    ▼
반려동물 그룹 선택
    │
    ▼
공간 종류 선택
    │
    ▼
실시간 촬영 가이드
    │
    ▼
영상 촬영 ◀──── 재촬영
    │
    ▼
영상 업로드
    │
    ▼
분석 진행 상태 확인 ◀──┐
    │                  │
    │  [ AI 분석 ]      │
    │                  │
    ├── 실패 ──▶ 분석 실패 화면
    │              ├── 재시도 ──┘ (최대 3회)
    │              └── 재촬영 ──▶ 촬영 화면
    ▼
결과 화면
    │
    ▼
분석 결과 저장
```

> ※ AI 분석 단계의 상세 흐름은 **AI 설계서**를 따른다.

# 승인 기준

| 기능 | 승인 기준 |
| --- | --- |
| 반려동물 그룹 선택 | 선택한 그룹이 분석에 정상 반영되어야 한다. 미지원 그룹은 선택할 수 없어야 한다. |
| 영상 촬영 | 생활공간을 일정 시간 안정적으로 촬영할 수 있어야 한다. |
| 재촬영 | 촬영 영상을 폐기하고 처음부터 다시 촬영할 수 있어야 한다. |
| 업로드 제한 | 크기·길이·형식 기준을 초과한 영상은 업로드가 거부되어야 한다. |
| 비동기 처리 | 분석 요청 시 즉시 분석 ID가 반환되고 요청 타임아웃이 발생하지 않아야 한다. |
| 분석 진행 상태 조회 | 진행 단계와 진행률이 표시되고, 완료 시 결과 화면으로 전환되어야 한다. |
| 분석 시간 초과 | 제한 시간을 초과한 분석은 실패로 전환되고 재촬영이 안내되어야 한다. |
| 분석 실패 안내 | 실패 시 실패 화면으로 전환되고, 실패 단계에 맞는 행동이 안내되어야 한다. |
| 분석 재시도 | 재시도 가능할 때만 버튼이 노출되고, 3회 소진 후에는 재촬영만 안내되어야 한다. |
| 공간 종류 선택 | 선택한 공간에 해당하지 않는 항목이 점수와 서술에서 제외되어야 한다. |
| 객체 탐지 | 주요 객체를 탐지하고 위치를 표시해야 한다. |
| 탐지 신뢰 기준 | 기준 미달 객체가 점수와 마킹에 반영되지 않아야 한다. |
| 객체 추적 | 동일 객체의 중복 탐지를 최소화해야 한다. |
| 위험 객체 마킹 | 위험 객체마다 개별 이미지를 생성하여 시각적으로 표시해야 한다. |
| 환경 분석 | 반려동물 그룹 기준으로 분석 결과를 생성해야 한다. 탐지되지 않은 객체를 언급하지 않아야 한다. |
| Pet Fit Score | 종합 및 항목별 점수를 제공해야 한다. 동일 입력에 항상 동일한 점수가 산출되어야 한다. |
| 환경 개선 추천 | 분석 결과에 맞는 개선 방안을 제공해야 한다. |
| 분석 결과 저장 | 결과를 저장하고 다시 조회할 수 있어야 한다. |
| 기기 식별 | 다른 기기의 분석 결과가 조회되지 않아야 한다. |
| 분석 결과 삭제 | 결과와 함께 영상·이미지 파일이 삭제되어야 한다. 진행 중인 분석은 삭제할 수 없어야 한다. |
