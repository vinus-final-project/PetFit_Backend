# PetFit Backend dependencies
# Python 3.10 (fixed)
#
# The team standardizes on 3.10. Do not develop on a newer version:
# code using 3.11+ features (asyncio.timeout, TaskGroup, StrEnum, datetime.UTC)
# runs fine there but breaks for everyone on 3.10.
#
#   pip install -r requirements.txt
#
# NOTE: Keep this file ASCII-only.
# Older pip (< 23) decodes requirements files using the system locale
# (cp949 on Korean Windows) and fails on non-ASCII characters.
#
# Development and test packages are included below.
# Comment out the "dev and test" section for production deployment.
